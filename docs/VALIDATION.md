
本轮通过：

- C++ 数值测试：旋转高斯质心、D4σ、主轴角恢复；非法/非有限/空信号拒绝；解析焦散恢复 M²=1.4、束腰半径 250 μm、束腰位置 30 mm。
- C++ 测量测试：逐像素暗场后保留负噪声；非法 ROI、缺失暗场拒绝；满量程像素可检出。
- Node 端到端测试 1：两个并发请求的图像头和结果帧号一致；非法参数与外部 Origin 拒绝；异常请求后工作进程可继续使用。
- Node 端到端测试 2：16-bit 大端 PGM 解码；非固定分辨率输入；错误暗场产生无效结果；饱和帧禁止记录；新文件使暗场失效；截断文件/越界 ROI 拒绝；ZIP 包含 manifest 和未归一化的原始像素字节。

测试样本为合成数据；不推导真实设备精度、吞吐量或 ISO 符合性。代码提交 `1d8b34836ca4996933b812ad1b2ff73d922b0eed` 已通过 [GitHub Actions 三平台回归](https://github.com/aruchid/laser-beam-analyzer/actions/runs/41212497565)：`windows-latest`、`macos-latest`、`ubuntu-latest` 全部 success。Windows CI 执行 CMake x64 编译、C++ 数值测试和 Node 通道/归档/生命周期测试；没有运行真实相机、位移台或 Electron 桌面 UI。

- Node 生命周期测试：端口占用导致启动失败时，候选工作进程和临时资源被回收，原服务仍可访问。

## 浏览器验收

在当前真实页面执行：

1. 初始页面无光斑、无设备、无测量值；相机连接与采集不可用。
2. 导入 `tests/fixtures/synthetic-gaussian-16bit.pgm`：512×384、16-bit、明确合成 QA 图。恢复主轴 D4σ 约 167.944 / 99.967 px，质心 252 / 190 px，方向约 19.993°。
3. 未确认标定时，物理尺寸显示“—”，扫描追加不可用。
4. 修改标定后进入 SETTINGS CHANGED，记录按钮不可用；重新测量后才恢复。
5. 记录一个有效源图像；再次记录同一源图像显示拒绝信息，样本数仍为 1。
6. n=1 时标准差显示“—”，不把 0 作为标准差估计。
7. 导出实际会话 ZIP，用 Python `zipfile.testzip()` 验证完整性；提取所有 raw 文件核对 SHA-256，与 manifest 完全一致。
8. 桌面布局在 1440×1000 检查；默认窄窗口按两列重排。检查时浏览器控制台无错误。
